```markdown
# Todo App

A simple full-stack Todo application built for learning purposes.
```

## Features

- Add, view, and manage tasks
- Basic frontend + backend structure
- Easy to run locally

## Tech Stack

- Node.js
- JavaScript
- Express (backend)

## Getting Started

1. Clone the repository
```bash
git clone https://github.com/SankalpX12/todo-app.git
cd todo-app
```

2. Install Dependencies
```bash
npm install
```

3. Start the application
```bash
npm start
```
